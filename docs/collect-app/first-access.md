# First access — setting up the app

## 3.1 Opening the app for the first time

When you open SnappingTrail Collect for the first time, you will see the **Settings** screen. This is where you connect the app to your company's server.

## 3.2 Entering the company code

In the **Company code** field, type exactly the code your company provided. It is usually a short name (for example, <kbd>acme</kbd>).

:::note[Test environments]

If your company is testing the system in a separate environment (not production), the code may come with a suffix like <kbd>acme@dev</kbd> or <kbd>acme@hml</kbd>. Type it exactly as given — the app understands the suffix and configures the servers automatically.

:::

## 3.3 Validating the connection

After entering the code, tap **Validate**. The app queries the server to confirm the company exists and fetches the required configuration.

If validation succeeds, a message confirms the company registration. If it fails, check that you typed the code correctly and have an internet connection.

## 3.4 Saving and signing in

After validating, tap **Save**. The app takes you back to the Login screen. Tap **Sign in** — an authentication screen opens in the device's browser. Enter your email and password and confirm.

After signing in, you will see the list of **Projects** available to you.
